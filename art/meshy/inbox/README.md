# Meshy gelen kutusu

Meshy web sitesinden indirilen GLB dosyaları buraya yüklenir (GitHub → Add file → Upload files).
Claude dosyaları alır, `art/meshy/out/<pet>/` altına taşır ve `install_pet.sh` ile oyuna kurar.
Bu klasör Git LFS dışındadır (tarayıcı yüklemesi LFS'e yazamaz). Dosya başına tarayıcı sınırı 25 MB.
